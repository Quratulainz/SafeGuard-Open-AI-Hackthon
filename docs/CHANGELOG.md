# Changelog

## v0.3.2 portable distribution (2026-10-25)

- Added launchers for Windows, macOS and Linux, a prerequisite check, and an
  English first-run guide. Python remains a documented prerequisite.
- Removed Codex-cache discovery from the PowerShell startup helper.
- Added new-device and private database migration instructions. Fresh devices
  generate their own local token; no old credentials or account are required.
- Verified 182 Python tests, including four relocation/migration tests. The
  unchanged 58 JavaScript and 7 deployment tests passed in the same-day baseline.
- Native startup and relocation were tested on Windows. macOS/Linux launchers
  are supplied without claiming native OS acceptance.

## v0.3.2 — Scoped website checks and English date controls (2026-10-25)

- Added a current-page assessment path so usable ordinary websites can receive
  green after URL, transport/context, redirect and form checks find no warnings.
  This does not authenticate a company or certify transactions.
- Incomplete retrieval, challenge pages and unusable context explain that the
  page check could not complete, without implying that the website is fake.
- Ordinary login/same-origin form behavior is distinguished from out-of-band
  credential requests or upfront-payment inducements. Missing optional feeds
  alone do not force yellow; current adverse listings retain a caution floor.
- Added English calendar controls and form validation that do not inherit the
  operating system's native date-picker language.
- Documented first-use assistant permissions, automatic appearance, turning it
  off and the fact that automatic appearance does not scan pages.
- Explicit current-page scans collect bounded visible text and form structure,
  with sender/tab binding and no form values. Safe redirects, verified TLS and
  final-destination IP evidence remain required checks.
- Validation: 178 Python, 58 extension/display and 7 deployment-template tests
  passed. See [release acceptance](RELEASE_ACCEPTANCE.md) for real website results
  and the distinction between automated tests and installed-browser acceptance.

Final validation counts and the actual archive check are recorded in the
modification diary and the accompanying release acceptance report.

## v0.3.1 — English release (2026-10-25)

- English interface labels, notifications, rule explanations, assistant messages
  and model-output instructions across the application.
- English documentation and release materials, with `GETTING_STARTED.md` as the
  quick-start guide and English-only archive filenames and metadata.
- Multilingual input detection and intentional multilingual test fixtures remain
  supported; source-language evidence is distinct from interface language.
- Default rules/local-history behavior, optional service settings, local connection
  controls, three verdict colors and subscription workflows retain their scope.
- Known generated text in older history records is translated for display without
  changing saved input, evidence, decisions, dates or database records.
- The separately supplied competition PDF remains unchanged and is excluded from
  redistribution. No project-root license has been selected.
- Validation: 132 Python, 35 extension/display and 7 deployment-template tests
  passed (174 total); live dashboard checks confirmed all three English verdicts.

Validation for this release is recorded in the modification diary and the
archive's isolated acceptance report. Historical cloud/model results remain
historical; this language update does not create cloud resources or establish
new sponsor connectivity.

## v0.3 — Local-first release (2026-10-25)

- Python-only default rules and SQLite history, with optional local IP snapshots.
- Automatic extension connection, opt-in website assistant, three verdict colors,
  editable subscriptions and independent cancellation/renewal reminders.
- Optional Nightshift, H-MEM, Zetaris and BlackIPS interfaces with honest service
  status, data provenance, reproduction guides and cost-guarded deployment templates.
- Verified 130 Python, 33 extension/display and 7 deployment-template tests;
  clean-archive local HTTP acceptance also passed.
